# FavLinks - Full Stack Application

A full-stack web application that allows users to save, manage, and organize their favorite links. Built with React, Node.js, Express, and PostgreSQL.

🌐 **Live App:** https://favlinks-theta.vercel.app/

## Technologies Used
- React, Vite, Tailwind CSS
- Node.js, Express.js
- PostgreSQL (Neon)
- Deployed on Vercel + Render

## Features
- Create, Read, Update, Delete favorite links
- Data persists in cloud database
